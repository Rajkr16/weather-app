🌤️ SkyPulse — Weather Forecast App
A responsive real-time weather app built with HTML, CSS, and JavaScript using the OpenWeatherMap API.
🔗 Live Demo
View Live
✨ Features

Search weather by any city
Real-time temperature, humidity, pressure & wind speed
5-day weather forecast with icons
Glassmorphism dark theme UI
Smooth animations & fully responsive

🛠️ Built With
HTML · CSS · JavaScript · OpenWeatherMap API · Swiper.js · Boxicons
⚙️ Setup

Clone the repo
Get a free API key from openweathermap.org
Paste your key in script.js → const apiKey = 'YOUR_KEY'
Open index.html in browser
